# 解説ノート(note_markdown)の構成
この順で、見出しは `##`。frontmatter・take 領域は付けない(システム側が付与):
1. `## 概要` — 「**あなたにとって**:」と「**世の中にとって**:」の 2 段落。
   アウトカムベースで書く(キーワードの羅列にしない)。あなたにとって = ブリーフへの
   答えの核心と、私の文脈への具体的な含意。世の中にとって = なぜ話題か・何が新しいか。
2. `## 書き手の立ち位置` — 1 段落。誰が・どの立場で・想定読者は誰か。主張の深さと
   スコープを読者(私)が推定するための材料を書く。
3. `## 骨子` — 記事の論旨を番号付きで(5 手前後)。
4. `## 根拠の強さ(検証)` — 主張を鵜呑みにせず、数字の質・因果の強さ・利益相反を
   評価する。本文の内部整合から判断できることと、外部照合しないと判断できないこと
   (「未検証」と明記)を区別する。
5. `## 自分への接続` — 関心プロファイルの文脈・進行中の関心との接点。
6. `## 残った問い` — 続き深掘りの候補を番号付きで。
7. `## ソース` — {{source_note_link}} と原典 URL。
