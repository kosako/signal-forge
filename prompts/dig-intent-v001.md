私が深掘りの概要カード(またはあなたの返事)へ Telegram で送ったリプライを、種類で分けよ。
返事は書かない。指定 JSON のみを出力せよ。前置き・コードフェンスは不要。

# リプライの返信先
{{replied_to}}

# 私のリプライ
囲みの中が、分ける対象の私のリプライの本文である。
<<<DATA-{{nonce}}
{{reply}}
DATA-{{nonce}}>>>

# 出力仕様
次の JSON スキーマに厳密に従う:
{{schema}}
フィールド基準:
- kind: リプライの種類。question = 質問・続きの要求 / take = 感想・結論・評価 /
  both = 両方を含む。
- redig: 私がこの記事を、新しい観点で調べ直してほしい(もう一度深掘りしてほしい)と
  はっきり求めているときだけ true。その場の返事で足りる質問・感想・「もっと知りたい」
  程度の関心は false。
- 「答えを作れなかった」という知らせへの返信で、返事の作り直しを求めるだけのもの
  (「もう一度」など)は、kind = question・redig = false。
